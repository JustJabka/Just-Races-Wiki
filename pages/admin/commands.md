# Commands

JustRaces provides some utility commands for the server admins and the datapack creators

| Command | Description | Permission |
| --- | --- | --- |
| `/justraces reload` | Reloads all configuration files and registries. | `justraces.command.justraces.reload` |
| `/getrace <player>` | Gets player's race. | `justraces.command.getrace` |
| `/setrace <player> <race>` | Sets a player's race. | `justraces.command.setrace` |
| `/selectrace <player>` | Displays race selection dialog to the player. | `justraces.command.selectrace` |
